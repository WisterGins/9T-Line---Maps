# 9T Line – Maps

Rhythm game maps for **9T Line**: the line runs by itself, you turn it on the beat. Plays in the browser, no install.

▶ **Play:** https://wistergins.github.io/9T-Line---Maps/

| Map | Song | Link |
|---|---|---|
| Yoru ni Kakeru | YOASOBI – 夜に駆ける | https://wistergins.github.io/9T-Line---Maps/yoru-ni-kakeru/ |

**Controls:** PC — Space / X / Z to turn. Phone — tap the screen. Settings in the menu: road width, speed (score scales with both), turn keys, graphics (Light for phones), latency calibration.

Music: YOASOBI – 夜に駆ける (Yoru ni Kakeru). All rights to the song belong to its owners.
